# Private Chat Application

A **real-time private chat application** with admin-controlled user management. This project demonstrates the use of modern web development tools and best practices to build a scalable and interactive application.

---

## Features

- **Real-time Messaging**: Send and receive messages instantly.
- **Admin Controls**: Admins can add users and manage conversations.
- **User Authentication**: Secure login/logout functionality.
- **Responsive Design**: Fully responsive user interface.
- **File Uploads**: Supports uploading attachments in chats.
- **Modern Stack**: Built using Node.js, Express.js, and EJS template engine.

---

## Live Demo

Check out the live project: [Private Chat Application](https://private-chat-application-bize.onrender.com)

---

## Technologies Used

- **Backend**: Node.js, Express.js
- **Frontend**: EJS template engine
- **Database**: MongoDB
- **Styling**: Custom CSS
- **Real-time Communication**: WebSockets with `socket.io`
